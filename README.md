## About This Project
This assignment is a hands-on exploration of core computer science fundamentals. Over the course of 8 missions, I work through:
- How computers process information (IPOS model) and computer hardware/software.
- Navigating and managing files with the Unix Terminal.
- Operating system internals, process management, paths, and permissions.
- Running programs and comparing compilers with interpreters.
- Number systems (binary, decimal, hexadecimal), data encodings, and building a Python conversion tool.
- Version control workflows using Git, branching, and GitHub Pull Requests.
- How computer networks communicate, DNS resolution, and what happens when loading a webpage.
- A final review consolidating everything learned.

Each mission is housed in its own folder with its own documentation and was worked on and committed separately.

## Running the Python Number Converter
In Mission 5, I built a terminal-based number converter in Python. You can run it directly:

```bash
python3 mission-05-numbers-data/number_converter.py
```

It takes a positive decimal integer and prints its binary and hexadecimal representations.
